# Программа для тренировок

Простое локальное приложение для браузера:

- календарь тренировок;
- база упражнений;
- упражнения, привязанные к конкретным дням.

Как открыть:

1. Откройте файл `index.html` в браузере.
2. Все изменения сохраняются в `localStorage` этого браузера на вашем компьютере.

Что уже есть:

- выбор дня в календаре;
- добавление и удаление упражнений;
- планирование упражнений на дату;
- очистка плана на день.
